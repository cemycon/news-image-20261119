# News Image: 19 November 2026

One image summing up world news on 19 November 2026.

Run with Node 22:

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

The output directory defaults to `/output` when `MAKEFUN_OUTPUT_DIR` is not set.
